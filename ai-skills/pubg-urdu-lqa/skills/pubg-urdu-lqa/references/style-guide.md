# PUBG MOBILE Urdu style guide

## Register
Use concise, natural Standard Pakistani Urdu. Game UI should be immediately understandable and compact.

## Translation discipline
- Translate meaning, not English word order.
- Do not over-localize product names or protected terminology.
- Avoid unnecessary literary vocabulary.
- Avoid adding honorific, religious, or culturally loaded wording that is absent from the source.
- Keep repeated source concepts translated consistently.

## Formatting
- Preserve source punctuation where structurally required.
- Preserve intentional spaces.
- Preserve line breaks and line-break count.
- Preserve numbers, placeholders, tags, and variables.
- Do not add a final period if the source has none.

## Existing production decisions
Use the user's established PUBG MOBILE Urdu terminology as the default source of truth. New decisions must not silently contradict older approved terminology.

## QA mindset
When reviewing a translation, distinguish:
1. objective error,
2. terminology inconsistency,
3. acceptable alternative wording,
4. source ambiguity.

Only the first two normally require correction.
