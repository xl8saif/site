# PUBG MOBILE Urdu terminology

These are production terminology decisions. Prefer these forms consistently unless a newer client-approved glossary explicitly supersedes them.

| English | Preferred Urdu |
|---|---|
| Official | آفیشل |
| Esports | ای سپورٹس |
| Hidden Leaf Center | پوشیدہ پتّا سینٹر |
| Valley of the End | اختتام کی وادی |
| Brainrot | برین راٹ |
| Creation Mode | تخلیق موڈ |
| Creator | کریئٹر |
| Creation | کریئیشن |
| World of Wonder (WOW) | ورلڈ آف ونڈر (WOW) |
| Creation Shop | کریئیشن شاپ |
| Master Creator II | Master Creator II |

Protected terms include:
- Discord
- Mission Card
- WOW Tokens
- World of Wonder (WOW) when used as the product/mode name

Do not normalize an established approved term into a different synonym merely because the alternative is linguistically possible.

For newly encountered terminology:
1. Inspect context.
2. Check the source/client glossary if available.
3. Prefer consistency with existing approved PUBG Urdu terminology.
4. If no safe decision exists, mark Query rather than inventing a term.
